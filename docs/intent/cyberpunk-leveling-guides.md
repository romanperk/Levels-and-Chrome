# Statement of Intent: Cyberpunk 2077 Leveling Guides

Confirmed by the project owner on 2026-11-07.

- **Outcome:** A web app with step-by-step Cyberpunk 2077 leveling guides in the style of Diablo IV. Each one takes a build from level 1 to endgame.
- **Attributes and perks:** Listed level by level, showing exactly where each point goes.
- **Cyberware and gear:** Listed in stages of about 10 levels, following the tier changes, with what to buy or use, recommended weapon slots, and where to get them. The author sets each stage's level range.
- **Phantom Liberty:** Every guide is clearly labeled as base game or Phantom Liberty, and the route itself can differ between the two.
- **User:** The owner first, then players who know what build they want but not how to get there, often reading on a phone or second screen while playing.
- **Why:** Planners and guides show the finished build but not the route, and players get stuck on what to choose while leveling. It is also a fun project.
- **Success:** The owner can play a new character from start to endgame using only their guide, without searching elsewhere for what to do next.
- **Constraints:** The owner is the only author in V1, with 2-3 guides for the current patch only. Guides are stored as structured data, so the move to accounts and a database stays cheap.
- **Later, not V1:** Sign-up, backend and database so anyone can publish guides, a game database for authors to pick guns, cyberware, attributes and relic points from, then auto-generated routes.
- **Out of scope:** A public build planner, comments and ratings, older patches, and mods.
